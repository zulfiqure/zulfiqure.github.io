# zulfiqure.github.io

Personal academic website of Zulfiqure Ali, built with [Quarto](https://quarto.org).

## How to update

1. Edit `index.qmd` in Positron.
2. In the Terminal, run `quarto render` (this rebuilds the `docs/` folder).
3. Commit and push. GitHub Pages publishes the `docs/` folder at https://zulfiqure.github.io within a minute or two.
